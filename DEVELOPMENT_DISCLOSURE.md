# Development Disclosure

This public repository is a clean reconstruction of a previously used 20-skill concept.

The exact skill names were preserved from prior user-authored configurations. The public definitions, routing policy, permission taxonomy, evaluation harness, installer, tests, documentation, and plugin packaging were rebuilt for this repository.

AI tools assisted with drafting, implementation, and review under human direction. Every public claim is intended to be verifiable from repository files or GitHub Actions. The repository does not publish private prompts, chat histories, machine paths, account data, credentials, or production automation state.

`instruction-audited` means the files pass the repository's structural, routing, policy, privacy, and packaging tests. It does not mean every skill has been exercised against every ChatGPT or Codex host, connector, operating system, or external service.
