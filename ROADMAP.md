# Roadmap

## 0.1.x — harden the public contract

- Collect external false-positive and false-negative routing reports.
- Add Windows and macOS installer jobs.
- Add signed release provenance where the hosting environment supports it.
- Add a marketplace smoke test when a stable non-interactive host interface is available.

## 0.2.0 — host integration evidence

- Test plugin discovery in supported ChatGPT and Codex surfaces.
- Record versioned host behavior without treating one model release as universal.
- Add optional reference adapters only when they can remain credential-free and synthetic.

## Later

- Split domain-specific packs only if the 20-skill initial list becomes too large for reliable discovery.
- Publish benchmarks for description compression and skill collisions.
- Add third-party translations without changing canonical names.

No roadmap item implies a commitment to autonomous account control, hidden personal profiling, or bundled credentials.
