# Changelog

All notable changes are documented here.

## 0.1.0 - 2026-08-30

### Added

- twenty modular skill contracts across intelligence, builders, orchestration, decision, knowledge, and execution support;
- current-style Codex plugin manifest and per-skill interface metadata;
- nine explicit-first safety gates for higher-impact capabilities;
- deterministic catalog loader, router, validator, evaluator, and install-preview CLI;
- generated `SKILL.md` and `agents/openai.yaml` surfaces;
- 74 routing and boundary evaluation cases;
- public-data audit, documentation, tests, CI, and release automation;
- truthful `spec_validated` maturity classification.

### Excluded

- credentials and account configuration;
- personal memory and private project state;
- live desktop, inbox, API, or file-system integrations;
- claims of unattended operational reliability.
