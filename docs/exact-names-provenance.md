# Exact-Name Provenance and Public Reconstruction

The canonical list contains 20 names recovered from prior user-authored skill configurations. The names and order are preserved as a compatibility contract.

The public repository does **not** claim that every prior private instruction was copied or that the historical set had complete production validation. Instead, each definition was reconstructed around:

- one narrow job;
- clear trigger and non-trigger boundaries;
- visible permission labels;
- explicit inputs and outputs;
- imperative steps and stop conditions;
- positive and negative examples;
- routing and policy evaluations;
- honest `instruction-audited` and `host-dependent` labels.

This approach preserves the reusable idea without publishing private paths, account integrations, user profiles, hidden memory, production state, or confidential operating policies.
